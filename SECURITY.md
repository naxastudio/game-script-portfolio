# Security Policy

This repository focuses on legitimate game development, approved modding, QA tooling, accessibility, and learning examples.

## Not Supported

Please do not submit or request:

- Cheats or unfair gameplay automation
- Anti-cheat bypasses
- Exploit chains
- Account abuse
- Credential collection
- Hidden telemetry
- Malware or persistence mechanisms

## Reporting Issues

If you find unsafe behavior in a public example, please report it privately when possible. Include:

- Affected file or example
- Reproduction steps
- Expected impact
- Suggested mitigation, if available

Security fixes should remove unsafe behavior without publishing instructions that enable misuse.
