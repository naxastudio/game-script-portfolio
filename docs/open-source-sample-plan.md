# Open Source Sample Plan

This document defines the public examples planned for the portfolio. Each sample should be small, readable, and useful on its own.

## Sample Quality Bar

Every public sample should include:

- Clear README
- Setup instructions
- Short feature list
- Known limitations
- Simple test or manual verification notes
- No private client code
- No secrets or account-specific configuration

## Available Samples

### HTML5 Arena Demo

A browser-based game loop example for small interactive demos.

Current features:

- Canvas rendering
- Player movement
- Enemy spawning
- Collision handling
- Score and restart flow
- Pause/resume control

Location: `open-source/html5-arena-demo`

## Planned Samples

### Unity Quest System

A compact Unity C# example showing how to structure quests, objectives, rewards, and progress state.

Planned files:

- Quest model
- Objective model
- Quest manager
- Example reward handler
- Minimal usage scene or pseudocode setup guide

### Minecraft Message Kit

A Java utility sample for Paper/Spigot plugins.

Planned features:

- Message formatting helper
- Cooldown manager
- Simple reward utility
- Permission-safe command example

## Growth Notes

The portfolio should prioritize polished, small examples over large unfinished projects. A visitor should understand the quality of the work within the first minute.
