# Contributing

Thank you for helping improve this game scripting portfolio. Contributions should make the repository more useful for developers, server owners, and creators reviewing open-source game development work.

## Good Contributions

Useful contributions include:

- Clearer documentation
- Small public sample scripts
- Better setup instructions
- Bug fixes in public examples
- Testing notes
- Architecture notes for Unity, Minecraft, FiveM, or web game examples

## Out Of Scope

This repository does not accept:

- Cheats or unfair competitive gameplay tools
- Anti-cheat bypasses
- Account automation or spam tooling
- Code that violates a game, platform, engine, or marketplace terms of service
- Hidden telemetry, credential collection, or unsafe network behavior

## Pull Request Checklist

Before opening a pull request:

- Keep the change focused
- Explain the reason for the change
- Add documentation for new examples
- Avoid secrets, tokens, or account-specific data
- Confirm the change fits the ethical scripting scope

## Style

- Prefer readable code over clever code
- Document assumptions and supported versions
- Keep examples small enough to learn from
- Separate configuration from behavior where possible
