# Open Source Game Dev Samples

This folder contains small, readable samples for game scripting, plugin development, and interactive game prototypes.

## Projects

| Project | Stack | Good For |
| --- | --- | --- |
| `unity-quest-system` | Unity C# | RPG quests, simulator tasks, objective tracking |
| `minecraft-message-kit` | Java | Paper/Spigot plugin utilities |
| `html5-arena-demo` | HTML5 Canvas | Browser game prototypes and interactive demos |

## Why These Samples Exist

These projects are compact on purpose. They are meant to show clean structure, practical gameplay logic, and code that can be adapted quickly for client work.
