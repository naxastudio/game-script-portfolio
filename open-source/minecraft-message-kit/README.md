# Minecraft Message Kit

Small Java utility classes for Paper/Spigot plugins.

## What It Shows

- Config-friendly message formatting
- Placeholder replacement
- Cooldown tracking
- Weighted reward selection
- No database or external dependency required

## Files

- `MessageFormatter.java`
- `Cooldowns.java`
- `WeightedRewards.java`

These classes are intentionally framework-light so they can be copied into plugin projects.
